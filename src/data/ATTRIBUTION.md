## Periodic table data

This dataset is adapted from [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) by Bowserinator and contributors.

The source dataset is licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). The adapted data in periodic-table.json is made available under the same license. Please retain this attribution and license when redistributing the dataset.

Changes made for Chemistry Studio: selected properties for the 118 recognized elements were retained; hypothetical element 119 was excluded; predicted categories were normalized to “unknown”; and gas densities are converted to g/cm³ when the source supplies that value. Source summaries and references are retained.
